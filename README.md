# Test task for auto-bnp

## Каталог товаров с корзиной (React)

Мини-приложение на **React** для просмотра каталога товаров и управления корзиной.

## Технологии

Проект реализован с использованием следующего стека:

- **React**  
  Построение пользовательского интерфейса

- **TypeScript**  
  Применяется для строгой типизации данных.

- **Redux Toolkit**  
  Используется для управления глобальным состоянием приложения (каталог, фильтры, корзина).

- **React Router**  
  Отвечает за навигацию между страницами каталога и корзины.

- **CSS Modules**  
  Используются для изоляции стилей компонентов и предотвращения конфликтов CSS-классов.

- **FakeStore API**  
  Используется как внешний источник данных о товарах и категориях.  
  https://fakestoreapi.com/

## Функциональность

### Каталог товаров

- отображение товаров в виде карточек
- карточка товара содержит:
  - изображение
  - название
  - цену
  - краткое описание
  - кнопку «Добавить в корзину»
  - индикатор наличия товара (тут не совсем понятно, таких данных нет в API)
- поиск по названию товара
- фильтрация по категориям
- сортировка:
  - по цене
  - по названию
- пагинация:
  - 12 товаров на странице
  - переключение между страницами

### Корзина

- отображение добавленных товаров
- изменение количества товара (`+ / -`)
- удаление товара из корзины
- подсчёт общей стоимости
- иконка корзины с badge (общее количество товаров)
- toast уведомления
- сохранение состояния корзины в `localStorage`

### UI / UX

- адаптивная вёрстка
- loader при загрузке данных
- пустые состояния для корзины и каталога
- disabled-состояния кнопок
- поддержка светлой и тёмной темы

## Начало работы

### Требования

Для установки и запуска проекта необходимы:

На момент разработки использовались версии:  
**Node.js** `v24.11.0`
**npm** `v11.2.0`

Проверка установленных версий:

```bash
node -v
npm -v
```

1. Клонировать репозиторий:

```
git clone <repository-url>
cd <project-folder>
```

2. Установить зависимости:
   Команда `npm install`

3. Настроить переменные окружения:

- Переименовать файл `.env.example` в `.env`

4. Запустить проект в режиме разработки:

- Команда `npm run dev`

  [link](https://test-task-auto-otg6ysstk-denis-nedelkos-projects.vercel.app)
